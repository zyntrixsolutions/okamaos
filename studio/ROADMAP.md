# Okama Studio Roadmap

## Milestones

### Studio 0.1 - MVP
- [x] Next.js Studio shell
- [x] Dashboard, Studio, Learn, Library, and Settings views
- [x] AI model selection with Gemini and Qwen options
- [x] Browser preview and `.ok` export flow

### Studio 0.2 - Agentic Building
- [x] Agent panel with file-aware tool calls
- [x] Local project version history
- [x] Branch, issue, commit, and pull-request style project workflow
- [x] Structured Python/Pygame learning hub

- [x] Local dev-store API routes
- [x] Publish-to-dev-server package flow
- [x] Studio branding and browser metadata

- [x] Add Studio sidebar link to OkamaOS Pages downloads
- [x] Add Dashboard download and manual actions
