# OkamaOS — "WHAT IF" Teaser Trailer Script (Cryptic / Minimal)

## Overview

| Attribute  | Value                              |
| ---------- | ---------------------------------- |
| Title      | *"WHAT IF"*                        |
| Runtime    | 30–45 seconds                      |
| Tone       | Minimal · Enigmatic · One question  |
| Palette    | Black screen only. Red pulses.     |
| Music      | Single sustained bass note. No beat.|
| Target     | Everyone — curiosity-driven        |
| Primary CTA| A single URL. No copy.             |

---

## Script

---

### 0:00–0:08 — THE SETUP

**[BLACK SCREEN. No sound. 4 seconds.]**

**[Single red dot appears in center. Small. Pulsing slowly.]**

> **VO (whispered, almost a question):**
> *"What if..."*

**[Pause. 2 seconds.]**

> **VO:**
> *"...the game paid you?"*

---

### 0:08–0:18 — THE REVEAL (PART 1)

**[Red dot expands. Becomes a thin vertical line.]**

**[Screen splits. Left side — a PC. Right side — a controller.]**

**[The PC powers on. Single LED. The controller lights up.]**

**[Both fade into a single red Okama mark.]**

> **VO:**
> *"No desktop."*
> *"No browser."*
> *"Just the game."*

---

### 0:18–0:28 — THE REVEAL (PART 2)

**[Okama mark dissolves into a grid of small red squares.]**

**[One square glows cyan. Then another. Then another.]**

**[They form a wallet icon. Then a token symbol. Then an NFT frame.]**

> **VO:**
> *"Earn by playing."*
> *"Own what you win."*
> *"On-chain."*

---

### 0:28–0:40 — THE CLOSE

**[Everything fades to black.]**

**[Single line of white text appears, typing itself:]**
```
okamaos.zyntrix.solutions
```

**[Pause. 3 seconds.]**

**[Red pulse. Fade to black.]**

---

## Music & SFX

| Moment       | Direction                             |
| ------------ | ------------------------------------- |

| Red dot pulse | Subtle thud on each pulse             |
| PC/controller power | Single synthetic chime            |
| Cyan squares | High-pitched ping per square          |
| URL typing   | Mechanical keyboard sound             |
| Final fade    | Bass drone cuts to silence            |
