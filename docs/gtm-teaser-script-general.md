## Scene-by-Scene Script

---

### SCENE 1 — THE PAIN (0:00–0:12)

**[BLACK SCREEN. Total silence.]**

> **VO (calm, almost bored):**
> *"Boot the PC. Wait for the desktop. Open the launcher. Wait for updates.
> Click through the settings. Find the game. Pray the controller works."*

**[Rapid cuts, each ~1s:]**
- Windows desktop — 47 icons, system tray chaos
- "Installing update 1 of 47..."
- DualSense controller on a desk — unpaired, unused
- $600 price tag on a PS5 box

**[HARD STOP. All cuts freeze to black.]**

**ON-SCREEN TEXT (Okama red, slow pulse):**
```
There is a better way.
```

---

### SCENE 2 — THE BOOT (0:12–0:22)

**[Sound of a single power button click. LED blinks once.]**

**[SCREEN: OkamaOS splash — dark background, Okama mark glows red, fades into the
fullscreen shell UI.]**

> **VO (low, cinematic):**
> *"What if your PC just... booted into the game?"*

**[The shell appears — neon-red cyberpunk UI, no desktop, no taskbar, no clutter.
D-pad navigates to PLAY. Selection moves instantly.]**

**ON-SCREEN TEXT (white, stacked, each line timed to beat):**
```
No desktop.
No launcher.
No waiting.
```

**[Beat drops. Music shifts up hard.]**

---

### SCENE 3 — THE CONSOLE (0:22–0:38)

**[Fast montage — each cut ~1.5s, synchronized to music beats:]**

**CUT 1 — VOID STRIKER**
Vertical shoot-em-up. Particle explosions. Multi-phase boss battle. Screen shake.
> **ON-SCREEN:** `Console-grade games.`

**CUT 2 — PGDRIVE**
Top-down car racing on procedural city grid. Minimap. NPC cars. Smooth camera.
> **ON-SCREEN:** `Any x86_64 PC. No extra hardware.`

**CUT 3 — CONTROLLER**
Close-up: Xbox controller in hand. Shell d-pad nav, smooth and instant.
Bluetooth icon pulses. "Controller connected."
> **ON-SCREEN:** `Xbox. PlayStation. Bluetooth. Wired.`

**CUT 4 — GAME STORE**
Store catalog tiles — art, version, size. One press: download + install bar fills.
> **ON-SCREEN:** `Games are yours.`

**CUT 5 — BOOT TIMER**
Stopwatch overlay: cold power-on to fullscreen game shell in under 10 seconds.
Status bar: 185 MB RAM used.
> **ON-SCREEN:** `< 250 MB RAM. Built to be fast.`
