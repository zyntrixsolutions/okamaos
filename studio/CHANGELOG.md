# Okama Studio Changelog

## [0.3.1] - 2026-05-02

### Added
- Added a visible OS Downloads link in the Studio sidebar that opens the OkamaOS Pages downloads section.
- Added a Dashboard action for downloading OkamaOS from the public Pages portal.
- Added an OS Manual quick action so creators can jump from Studio to install, update, package, and Dev Console docs.

### Changed
- Bumped Studio package metadata and `VERSION` to `0.3.1` for the ecosystem-link release.

## [0.3.0] - 2026-05-02

### Added
- Dev-server game hosting flow for publishing local `.ok` packages to OkamaOS over LAN.
- Server tab and dev-store API routes for catalog, upload, remove, and info.
- Okama Labs Studio branding.

### Fixed
- Console-side `.ok` ZIP package support.
- Key-repeat navigation and Dev Console ANSI/tail-scroll behavior in the matching OkamaOS update.
